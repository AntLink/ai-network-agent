# Network Runbook Skill

Use this skill when the agent needs an operational procedure or troubleshooting workflow.

Runbooks should be:

- vendor-aware,
- evidence-driven,
- read-only first,
- approval-aware for changes,
- concise and actionable.

Read `references/runbooks.md` before writing operational guidance.
