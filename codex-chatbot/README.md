# Codex Chatbot

9Router-powered network operations chatbot with web UI.

## Quick Start

```bash
pip install -r requirements.txt
cp .env.example .env   # edit with your 9Router key
python main.py
```

Open http://localhost:8100

## Features

- Free LLM models via 9Router (Llama 3.3 70B, Qwen, Gemini, GPT-4o)
- Streaming and non-streaming responses
- Conversation history
- Model selector
- Network ops focused system prompt
